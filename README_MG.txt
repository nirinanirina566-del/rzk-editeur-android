RZK EDITEUR - Android starter project

INONA NO AO ANATY?
- Android app Kotlin + Jetpack Compose
- Safidy sary avy amin'ny téléphone
- Mandefa sary any amin'ny backend Render
- Manara-maso ny Topaz process ary mahazo download URL
- GitHub Actions workflow hanamboatra APK tsy mila Android Studio

FOMBA FAMPIDIRANA AO GITHUB (amin'ny téléphone):
1. Sokafy ny repository GitHub-nao.
2. Tsara kokoa ny mamorona repository vaovao: rzk-editeur-android.
3. Ao amin'ny repository, tsindrio Add file > Upload files.
4. Sokafy/avaho ny ZIP, ary ampidiro ny votoatin'ny dossier RZK_EDITEUR_Android_Project (fa tsy ilay dossier ivelany).
5. Commit changes.
6. Sokafy Actions. Raha tsy mandeha ho azy, fidio "Build RZK EDITEUR APK" > Run workflow.
7. Rehefa vita, sokafy ilay run maitso, midina any Artifacts, ary alaivo ny RZK-EDITEUR-debug-apk.zip.
8. Esory ilay ZIP ary apetraho ny app-debug.apk.

ZAVA-DEHIBE:
- Tsy APK efa vita ity ZIP ity; source project izy ity.
- Ny APP_ACCESS_TOKEN dia tsy tafiditra ao amin'ny app. Ampidiro ao amin'ny app amin'ny findainao rehefa mampiasa azy.
- Aza mizara ilay token amin'olona ary aza apetaka ao amin'ny GitHub.
- Ny endpoint sy JSON format Topaz dia mila andrana amin'ny tena kaonty. Raha tsy mitovy ny valin'ny backend dia mety mila fanitsiana.
- Ny backend ankehitriny dia mampiasa Topaz Standard V2. Tsy mbola voamarina fa mamoaka 4K na manao AUTO color.
- Tsy azo antoka 100% ny fitazonana ny tarehy amin'ny AI; ity app ity tsy mampiasa face replacement.
